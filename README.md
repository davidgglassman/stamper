# Stamper

Node CLI for scaffolding projects from templates.

<br>

## Installation

Ensure you have Node.js installed on your computer.

1. Clone the repository to your local machine using Git:

   ```bash
   git clone https://github.com/davidgglassman/stamper.git
   ```

2. Navigate to the project directory:

   ```bash
   cd stamper
   ```

3. Install the project dependencies:

   ```bash
   npm install
   ```

4. Run the project in development mode:
   ```bash
   npm run serve
   ```

5. (OPTIONAL) Link the project globally to make the `stamper` command available on your system:
   ```bash
   npm link
   ```
   This step allows you to run the `stamper` command from anywhere in your terminal.

<br>

## Usage

After installation, you can run the CLI by typing `stamper` in your terminal. This command will display a list of examples that you can choose from, demonstrating various CLI functionalities:

- Basic Example
- Chalk Example
- Figlet Example
- Inquirer Confirm Example
- Inquirer Example
- Inquirer List Example
- Ora Example

Select an example to run it and see the functionality in action.
